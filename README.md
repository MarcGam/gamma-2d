# gamma-2d

Libreria 2D minimalista ispirata a p5.js per giochi e animazioni canvas.

## Installazione via CDN

```html
<script src="https://cdn.jsdelivr.net/gh/MarcGam/gamma-2d@1.0.0/gamma-2d.js"></script>
```

## Uso minimo

```html
<script>
function setup() { createMiniCanvas(800, 600); }
function draw() {
    background(30);
    fill('cyan');
    text('Ciao!', 20, 20);
}
</script>
```
